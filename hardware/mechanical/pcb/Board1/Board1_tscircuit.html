⑥ 常见疑问

1) MAX98357 模块的 7 个排针里没有 SPK+ / SPK-？喇叭到底接哪？

对，模块的 7 个排针 = VIN / GND / SD / GAIN / DIN / BCLK / LRC，没有 SPK+ / SPK-。 原版板子上 vin（本页 J2）就是给模块的座子：

  1. VIN→J2-1（这是 5V，不是 3.3V）、GND→J2-2、DIN→J2-5（D0）、BCLK→J2-6（D5）、LRC→J2-7（D4）；SD/GAIN 悬空。
  2. 喇叭（头部 1.25 插头）直接接模块自带的绿色 2P 接线端子（SPK+/SPK-），转接板本身不经过喇叭信号。
2) 我看到 D6、D7 没接线，舵机接在 D3 和 D9？

对：原板D6、D7 悬空。舵机信号实际是：

  • Y 舵机（上下/俯仰）→ D3 / GPIO4（H4 左排第 4 脚 → J4 第 3 脚 S）
  • X 舵机（左右/水平）→ D9 / GPIO8（H3 右排第 5 脚 → J3 第 3 脚 S）

注意舵机 3P 座脚序是标准的 1=GND(黑)、2=+5V(红)、3=SIG(黄/白)，不是旧的“1=5V、2=SIG、3=GND”。 D5 是 I2S BCLK（给功放），不是舵机。

3) 这个 USB-C 只有 6 个脚，D+/D- 呢？

这板的 USB-C 是只供电的：6 个焊盘 = GND(A12/B12) + 5V(A9/B9) + CC1(A5) + CC2(B5)， 没有 D+/D- 数据线。程序下载/串口走 XIAO 模块自己那个 USB-C，这块转接板只负责给整机供电。

4) “B 方案走板子（官方设计）”是不是走不通？

走得通：原版嘉立创工程含原版原理图 + PCB 布局，可直接在嘉立创专业版打开。本页两张图就是按该工程的 真实元件坐标、真实封装形状、真实板框重新生成的（不是反推示意图）。

5) 为什么不用照片还原，改用工程文件？

照片只能看个大概；.epro2 里每个引脚、每条铜箔、丝印网络名（D0..D10、USB、GND、3.3、S）都是精确的。 本页图/表按 PCB 丝印 + 铜箔逐线核对，比反推可靠。装板前建议用万用表通断档复核一次。
